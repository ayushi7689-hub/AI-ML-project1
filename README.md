# Machine Learning – Data Cleaning & Preprocessing

This project focuses on cleaning and preprocessing a student performance dataset for Machine Learning. The project includes handling missing values, duplicates, outliers, categorical encoding, feature standardization, and splitting data into features (X) and target (y).

**Tools:** Python, Pandas, NumPy, Scikit-learn
